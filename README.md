# rose-reagan.github.io

Personal academic website for Rose Reagan, built with [Jekyll](https://jekyllrb.com) and the
[AcademicPages](https://github.com/academicpages/academicpages.github.io) template, hosted free on GitHub Pages.

## Where things live

| To change...                     | Edit this file                          |
|----------------------------------|-----------------------------------------|
| Name, sidebar bio, links, email  | `_config.yml` (the `author:` block)     |
| Home page text                   | `_pages/about.md`                       |
| Research page                    | `_pages/research.md`                    |
| Top menu                         | `_data/navigation.yml`                  |
| Colors                           | `_sass/theme/_rose_light.scss` / `_rose_dark.scss` |
| Profile photo                    | replace `images/profile.png` (square works best) |
| CV                               | upload `files/RoseReaganCV.pdf`         |
| Publications                     | add files to `_publications/` (copy `_EXAMPLE-copy-me.md`) |

Every commit to the `master` branch rebuilds the site automatically within ~1–2 minutes.
